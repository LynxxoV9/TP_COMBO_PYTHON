# Travaux Pratiques Python – Licence 3 ESA-Tg 🔥

Ce repository regroupe l’ensemble des travaux pratiques réalisés dans le cadre du module Python en Licence 3 à l'ESA Togo.  
L’objectif principal est de renforcer la LOGIQUE algorithmique, la RIGUEUR en programmation, la capacité à RESOUDRE des problèmes concrets rencontrés dans le monde professionnel, et à REPONDRE aux incidents de sécurité ❤️.

Chaque travail pratique correspond à un cas réel et aborde progressivement les fondamentaux jusqu’à un mini-projet de synthèse.

## Organisation du repository

Le dépôt est structuré en plusieurs dossiers, chaque dossier représentant un travail pratique indépendant avec sa propre documentation.

Contenu du repository :
- TP1 : Prise en main et structures de base
- TP2 : Fonctions et modularité
- TP3 : Listes, tuples et dictionnaires
- TP4 : Manipulation de chaînes de caractères
- TP5 : Fichiers (lecture et écriture)
- TP6 : Gestion des exceptions
- TP7 : Programmation Orientée Objet
- TP8 : Algorithmes et complexité
- TP9 : Manipulation de données CSV
- TP10 : Mini-projet de synthèse

Chaque dossier contient :
- Le code source du TP
- Un README.md spécifique expliquant le contexte, les objectifs et le fonctionnement

## Objectifs pédagogiques

Ce projet vise à :
- Développer une logique de programmation solide
- Comprendre les structures de données et les algorithmes
- Écrire un code clair, structuré et maintenable
- Appliquer les concepts à des situations réelles
- Préparer à des projets plus avancés et professionnels 💪
